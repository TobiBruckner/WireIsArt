# Wire Is Art — Federico Gauna Portfolio

> A minimalist landing page showcasing the wire sculptures of visual artist Federico Gauna.

[![Site](https://img.shields.io/badge/View%20Portfolio-Live-%238b7355?style=for-the-badge)](https://tobibruckner.github.io/WireIsArt/)
[![GitHub](https://img.shields.io/badge/GitHub-100000?style=for-the-badge&logo=github&logoColor=white)](https://github.com/TobiBruckner/WireIsArt)

## About the Artist

**Federico Gauna** is a visual artist who has been transforming simple strands of wire into meaningful sculptures since the age of 10. Every piece is meticulously handcrafted, intertwining each strand with dedication and a love for the craft. His work seeks to find beauty in minimalism, proving that even the simplest material can become an extraordinary piece of art.

## Sections

| Section | Description |
|---------|-------------|
| **Hero** | Intro with name, tagline, and call-to-action |
| **About Me** | Artist bio + profile photo with decorative frame |
| **My Works** | Responsive gallery of 8 wire sculptures with hover effects |
| **Contact** | Direct links to Instagram and WhatsApp |

---

## Features

- 🎨 **Elegant minimalist design** with warm earth-tone palette (cream / terracotta accent `#8b7355`)
- 📱 **Fully responsive** — mobile, tablet, and desktop optimized
- ✨ **Smooth interactions** — hover zoom on artwork, animated nav underlines, scroll-to-section navigation
- 🔗 **Social links** — opens Instagram / WhatsApp in new tab
- 📷 **Custom captions** — each sculpture displays its title on hover
- ⚡ **Zero dependencies** — pure HTML + CSS, no build step required

---

## Tech Stack

- **HTML5** — semantic structure
- **CSS3** — Grid / Flexbox, animations, responsive media queries
- **No frameworks** — lightweight and fast

## View Locally

```bash
# 1. Clone the repo
git clone https://github.com/TobiBruckner/WireIsArt.git

# 2. Enter the project
cd WireIsArt

# 3. Serve (any of these work):
python -m http.server 8000
# or
npx serve
# or just open index.html directly in your browser
```

Then open http://localhost:8000
